7. STEPS TO RUN THE APPLICATION
----------------------------------------------------------------

OPTION A — Docker Compose (recommended, requires Docker Desktop):

  1. Copy environment file:
       cp .env.example .env
       (edit APP_BASE_URL if deploying publicly)

  2. Start all services:
       docker compose up --build

  3. Open browser:
       Frontend : http://localhost:3000
       Backend  : http://localhost:8080
       API docs  : http://localhost:8080/api/...

  4. Shutdown:
       docker compose down

OPTION B — Local Development (requires Java 17+, Node 18+, PostgreSQL):

  Backend:
    1. Create PostgreSQL database "qrshare" with user "qrshare"
    2. Set environment variables (see .env.example)
    3. cd backend
    4. mvn spring-boot:run

  Frontend:
    1. cd frontend
    2. npm install
    3. npm run dev
    4. Open http://localhost:5173

8. ARCHITECTURE SUMMARY
----------------------------------------------------------------
  Backend  : Java 17 / Spring Boot 3 / Spring Security / Flyway / JPA
  Database : PostgreSQL 16 (Flyway migrations auto-applied)
  Storage  : Local filesystem (/temp-files), abstracted via interface
  QR lib   : ZXing (Google) — generates PNG QR codes
  Token    : 32-byte cryptographically secure random, stored as
             SHA-256 hash in DB; raw token delivered in QR URL
  Cleanup  : @Scheduled task runs every 5 minutes; deletes expired
             files and DB records
  Frontend : React 18 / TypeScript / Vite / Tailwind CSS
  Routing  : React Router v6 (SPA, nginx fallback configured)
  Proxy    : nginx in Docker forwards /api/* to backend:8080
