## Issues Fixed During Test Development

### Java 25 Compatibility
- Environment uses Java 25 (OpenJDK Temurin 25.0.4.1)
- Spring Boot 3.2.0 bundles Lombok 1.18.30 which fails on Java 25
- Fix: overrode lombok.version=1.18.38 in pom.xml
- Mockito Byte Buddy 1.14.x doesn't officially support Java 25
- Fix: added -Dnet.bytebuddy.experimental=true to maven-surefire-plugin argLine

### GlobalExceptionHandler improvements
- POST /api/files with no file part throws MissingServletRequestPartException (not
  MissingServletRequestParameterException) — was being swallowed by the generic 500 handler
- Fix: added @ExceptionHandler for MissingServletRequestPartException → 400
- Also added @ExceptionHandler for IllegalArgumentException → 400
- Also added @ExceptionHandler for MissingServletRequestParameterException → 400

### FileShareServiceTest strictness
- Mockito's STRICT_STUBS (default) rejects unnecessary stubbings per-test
- Fix: applied @MockitoSettings(strictness = Strictness.LENIENT) at class level
  and moved stubs into each individual test method to keep them precise

### CleanupServiceTest
- The doThrow() for fileStorageService.delete("key-missing") caused a
  PotentialStubbingProblem for calls to other keys under STRICT mode
- The lenient mode on CleanupServiceTest is not set; the test passes because the
  CleanupService catches all exceptions gracefully — the stub fires correctly
